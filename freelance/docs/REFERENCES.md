# 레퍼런스 활용 기준

기존 자료를 중복 복사하지 않고 이 저장소의 다음 폴더를 사용한다.

- `../../refs/ir/portfolio/`: 사용자 작업 26건과 일부 서식 분석용 경량 PPTX.
- `../../refs/ir/samples/`: 상장사 IR 샘플 21건.
- `../../design-kit/ir-styles/styles.json`: 기존 스타일 분류.
- `../../assets/fonts/README.md`: 승인된 폰트.

포트폴리오와 상장사 샘플을 균형 있게 참고하되 실제 작업과 맞는 페이지를 고른다. 폴더를 열거나 텍스트를 검색한 것만으로 시각 분석 완료라고 보고하지 않는다.

## 페이지 제작 전 기록

| 항목 | 적을 내용 |
|---|---|
| 실제로 본 페이지 | 파일명과 페이지 번호 |
| 정보 위계 | 제목·핵심 숫자·본문·주석의 상대 크기 |
| 배치 | 여백, 열 비율, 정렬 기준선, 요소 간 간격 |
| 이미지 | 실제 점유 면적, 크롭·비율, 이미지와 그래프의 균형 |
| 차트 | 무엇을 크게 읽게 하는지, 라벨·단위·목표 표시 |
| 이번 페이지 반영 | 구체적으로 가져올 원칙 2~3개 |
| 결과 검수 | 완성 화면을 레퍼런스 옆에서 비교한 차이·보정 |

참고 원칙은 적용하되 다른 고객 내용·숫자·이미지는 옮기지 않는다. 새 외부 공유본에 포트폴리오 전체를 포함하지 않는다.
