# 7p — 미해결 수정 요청

- 기준: v8의 7p.
- 요청: 70%·30% 원형 그래프, 각 파트별 이미지 삽입, 기존 IR 레퍼런스 참고.
- 유지: 상단 메뉴·제목 스타일·브랜드색·기존 수치와 이미지의 의미. 다른 페이지 보존.
- 수치: 70% 카피캣, 30% owooii 확보 목표. 현재 실적으로 바꾸지 않는다.
- v9 피드백: 사용자가 품질 부족 지적. 큰 원형 그래프·축소된 이미지·중복 문구·답답한 박스를 다시 검토해야 함.
- 상태: 요청 유지 / Adobe 환경 구성 중. 이번 환경 설정 작업에서는 추가 시안 미제작.
- 다음 실행: 레퍼런스의 실제 페이지 2~3개와 기준 7p를 비교하고, 이미지 크기·여백·정보 위계 기준을 기록한 다음 편집.
