# 인생사진첩 — 확정 요청과 미확정 사양

## 요청
- 폴더: `2026_11.16_인생사진첩`.
- 메인 InDesign, 보조 Illustrator. 바탕화면에 설치하지 않고 GitHub에서 이어서 작업.
- 어르신 사진 작품 활동북, 총 24p, 10명에게 각 2p.
- 남산정 PDF는 표지 시안 참고에만 사용. 내지나 이번 책의 사진·기관 자료가 아님.
- 너무 아기자기한 요소를 피하고 사진·읽기 쉬운 활자·절제된 여백 중심.
- 인사말·작가소개글은 추후 전달. '내일'은 고객 메시지 원문으로 실제 날짜 미확정.
- 새 원고와 사진이 준비되면 Claude에서도 계속 수정할 수 있어야 함.

## 원고 기준
- 제목 `인생사진첩`, 부제 `프레임에 담긴 나의 세상`.
- 기관: 동래구노인복지관 재가노인지원서비스센터.
- 지원 문구: 본 제작물은 부산사회복지공동모금회의 지원으로 제작되었습니다.
- 1p 표지(10명 작품 1장씩), 2p 인사말, 3p 프로그램 소개·8회기 주제·활동사진 3장.
- 4~23p 10명 작품 펼침면: 작가명·작품사진·작품 제목·설명. 작품 방향에 따른 틀 조정 가능.
- 24p 마무리: 활동사진 4~6장, 참여 어르신·강사·봉사자·기관 정보.

## 자료
- 수신: HWP 구성안, 남산정 PDF(표지 참고 전용).
- 미수신: 활동사진 ZIP, 작품사진 20장 ZIP. 현재 전송 한도 32MiB를 초과해 내려받지 못함.
- 다른 프로젝트의 `08.png`는 제외. 이전 Adobe 검색 결과의 노출 외에 이 작업 자료로 사용하지 않음.

## 미확정
- 판형·제본·도련·색상·ICC·인쇄소·마감. A4/3mm는 검토 구조의 임시값.
- 작가명·작가소개·작품 제목과 설명, 사진별 작가 대응, 소개 원고·회기 주제·활동 사진 선택, 기관/지원 로고 원본.

## 실행 조건
- API 목록 화면에서 InDesign/Illustrator API 모두 비활성화 확인. 계정 구매와 서버 실행 권한을 혼동하지 않음.
- Python은 자료/작업 관리, JSX는 실제 InDesign 문서 편집을 맡는 방식으로 준비.
- 이 클라우드 세션에는 실제 InDesign 실행 연결이 없으며 상시 실행 서버도 미배포. INDD·IDML·PDF 생성과 시각 검수는 아직 실행하지 않음.
