- `inputs/manuscript/「인생사진첩」 작품집 구성안 (4).hwp`: 원본 사본 보존·본문 추출 완료.
- `inputs/references/남산정 아리랑_활동북_인쇄-25.11.25.pdf`: 원본 보존·첫 표지 실제 화면 확인. 표지 참고만 허용.

- 원본 체크섬·수신 상태: `data/input-manifest.json`. 다른 프로젝트 이미지는 사용하지 않음.

## 준비 완료
- 고객 요청·HWP 본문을 대조한 `output/01_원고분석_제작계획.md`.
- `data/book-data.json`, `page-plan.csv`: 24p, 10명×2p, 표지10작품·소개3활동사진·마무리4~6활동사진.
- `asset-mapping.csv`: 20작품 및 활동사진 대응 입력 자리. 모든 작가 이름·실제 순서·사진 대응은 미확정.
- `scripts/BuildAlbum.jsx`: InDesign 네이티브 24p 검토 구조 생성 스크립트. 새 폴더에 INDD·IDML·검토 PDF와 보고서를 출력하도록 준비. 현재는 **구문 검증만 완료, 앱 미실행**.
- `CLAUDE.md`, `AGENTS.md`, `START-HERE.md`: 같은 GitHub 브랜치에서 Claude/Codex로 이어갈 수 있는 규칙과 시작 문구.
- 바탕화면/사용자 PC에는 설치하거나 파일을 기록하지 않음.

## 남은 일
1. 사진 ZIP을 32MiB 이하의 여러 파일로 다시 받거나 사용자가 GitHub에 직접 올린 자료 경로로 수신.
2. 사진 파일명·20작품 실물·작가 매핑·해상도·방향 확인. 표지에는 확인된 각 작가 1장씩 사용.
3. 인사말·작가소개·작품 제목/설명·프로그램/회기·마무리 원고와 기관/지원 로고 수신.
4. 판형·제본·도련·색상 사양 확인. 임시 A4/3mm를 최종 사양으로 간주하지 않음.
5. 실제 InDesign에서 JSX 실행·파일 열기·링크/폰트/오버셋/이미지 크롭·24쪽 출력 시각 검수.

## 실행 환경 사실
- PC 세 Adobe 앱 설치·로그인·구매: 사용자 확인.
- Adobe API 두 항목 비활성화: 사용자 콘솔 화면 확인. 기존 `automation/FEASIBILITY.md`는 기술 조사이며 계정에서 실행 가능한 상태를 뜻하지 않음.
- 개인 PC가 꺼진 상태의 서버 실행은 아직 미구성. 사용자 PC 앱에 원격 연결되어 있지도 않음.
- 현재 산출물은 원고 정리·페이지 설계·제작 스크립트이며 완성 INDD/IDML/PDF가 아님.
