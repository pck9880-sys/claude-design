# 준비 단계 검증

- HWP/PDF 원본 사본: SHA-256 일치.
- 입력 목록: 고객 첨부 4개만 기록, 수신 2개·ZIP 미수신 2개를 구분.
- 24쪽 연속 페이지, 10명×2쪽, 본문 작품 자리 20개, 표지 작품 자리 10개 확인.
- 모든 작가 펼침면이 짝수 왼쪽/홀수 오른쪽 4–5p부터 구성됨.
- InDesign JSX 및 데이터 include JavaScript 구문 확인. 실제 InDesign 실행 검증은 못 함.
- 다른 프로젝트의 08.png는 inputs에 없으며 배치 경로에도 없음.
- 사진 개수·사진 실물·해상도·작가 대응·인쇄 사양·실제 INDD/IDML/PDF 출력은 미검증.
