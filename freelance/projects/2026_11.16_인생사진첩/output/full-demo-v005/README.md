# 사진·원고를 채운24쪽 예시 — v005

사용자 허용에 따라 임의 자료로 실제 편집 느낌을 확인하는 시안. 가상 작가명·인사말·작품 설명·프로그램/8회기·명단을 넣었다. AI 생성20개 작품장면과4개 활동장면을 사용한다. 활동사진9칸에는 일부 장면을 반복했다. 실제 고객 자료/행사기록이 아니다.

- `인생사진첩_전체24p_사진원고예시_v005.pdf`: 전체 검토PDF.
- `전체24p_한눈에보기.png`: 전체 구성, `spread-*.png/.svg`: 펼침면.
- `data/demo_content_v005.json`: 예시원고·사진대응, 고객 book-data.json과 분리.
- `data/layout_demo_full_v005.json/.jsxinc`: 실제24쪽 좌표·프레임·텍스트·색상.
- `scripts/BuildDemoFullAlbumV005.jsx`: InDesign 네이티브 문서 생성 스크립트. 프로젝트 폴더 구조 유지 후 실행. 사진프레임 사분면 크롭을 포함해 편집가능한 객체로 생성하도록 준비. 실제 앱 실행은 미검증.

원고 구성:1표지(10장 모자이크),2인사말,3소개/8회기/활동3장,4~23작가10명×2쪽,24마무리/활동6칸/명단/기관. 오른쪽은 상단 작품제목+간단설명+큰 사진. 이번판에서 제목누락을 보완했다.

기관/지원 문구는 실제 제공 원고를 유지한다. 실제 로고가 없어 정식 로고 대신 임시 문자표기, 표지와 마지막에 ‘사진·인명·본문은 디자인 검토용 예시’ 안내를 넣었다.

재생성: `python scripts/build_demo_full_v005.py` → `python scripts/render_demo_full_v005.py`. FontTools, CairoSVG, pypdf, Pillow와 Pretendard 사용. 렌더 스크립트의 로컬 이미지 허용 옵션은 자체 생성SVG만 대상으로 한다. 외부 제공 SVG에는 적용하지 않는다.

전체24쪽·텍스트 폭/높이·대기문구0·15mm여백·우측제목10곳 검사. 실제 InDesign변환본의 문서 여백/펼침면/텍스트편집성은 실물 파일 별도 확인이 필요하다. A4·도련3mm는 여전히 임시 인쇄사양이다.
