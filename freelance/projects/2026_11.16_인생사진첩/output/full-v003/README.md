# 전체24쪽 구성 — full-v003

사용자가 전체 페이지 구성을 요청하여 v007 한 장의 디자인을 작가10명에게 적용했다. 예시 작가명·소설 원고는 사용하지 않았다. 사진은 사용자 요청대로 빈 프레임이며 추후 비례 맞춤으로 넣는다.

|쪽|내용|
|---|---|
|1|작품10장 모자이크 표지, 제목·부제·기관·지원표기|
|2|센터장 인사말|
|3|프로그램 소개,8회기 주제,활동사진3장|
|4–23|작가10명×2쪽. 왼쪽 작품+소개/글, 오른쪽 작품사진만 크게|
|24|함께한 순간들,활동사진6칸(원고4~6장 범위),참여자·기관정보|

작가별 유사 명도·저채도10색을 데이터에 보관했다. 사진·작가 매핑은 미확정 임시ID다. 오른쪽 사진만 구성은 이번 사용자 지시가 HWP의 오른쪽 제목/설명 계획보다 우선한다.

## 결과
- `인생사진첩_전체24p_구성_v003_검토용.pdf`: 24쪽 검토 PDF. 자체 SVG 출력으로 실제 InDesign 출력과 구분.
- `전체24p_한눈에보기.png`: 전체 구성.
- `page-*.png/.svg`, `spread-*.png/.svg`: 개별 페이지·펼침면.
- `page-map.csv`: 페이지 역할·작가ID·색상·사진ID 대응.

## InDesign 제작
프로젝트 폴더 구조를 유지하고 Pretendard Regular/Bold 설치 후 `scripts/BuildFullAlbumV003.jsx`를 InDesign 스크립트 패널에서 실행한다. 스크립트만 다른 폴더에 복사하면 데이터를 찾지 못한다. 기존 문서를 바꾸지 않고 새 facing-pages 24쪽 문서를 만들며 사방15mm 여백을 설정한다. 편집 가능한 텍스트·프레임·색상을 생성하고 `source/indesign/full_v003_<시각>/`에 INDD·IDML·검토PDF·보고서를 저장하도록 구성했다.

실제 앱 실행은 이 환경에서 불가하여 미검증이다. JSX 구문만 확인했으며 INDD가 이미 만들어졌다고 해석하지 않는다. 실행 후 보고서의 누락 링크/오버셋·폰트·전체 펼침면을 확인한다. A4·도련3mm는 임시값, PDF는 인쇄 납품본이 아니다.

## Claude 이어하기
기준 내용은 `data/book-data.json`, 좌표/스타일은 `data/layout_full_v003.json`. `python scripts/build_album_full_v003.py`가 기준 원고와 v007 디자인을 조합한다. 생성 데이터를 직접 수정한 뒤 빌드를 다시 돌리면 덮어쓰므로 지속할 배치 수정은 생성 스크립트에도 반영한다. 사진을 받으면 book-data의 자산 경로와 실제 작가 대응을 확인해 넣고 `scripts/sync_jsx_data.py`를 실행한다. 이후 생성 스크립트를 InDesign에서 실행한다.

검토 렌더는 `python scripts/render_full_v003.py` (CairoSVG, pypdf, Pillow 및 Pretendard 사용). 미수신 소개글·인사말·회기·기관정보·로고를 받기 전 완성 원고라고 보고하지 않는다.
