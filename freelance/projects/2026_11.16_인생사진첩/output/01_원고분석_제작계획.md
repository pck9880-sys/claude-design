# 인생사진첩 — 원고 분석과 제작 계획

## 확정 원고

HWP 전체 본문을 읽고 PrvText와 대조했다. 총 24쪽, 작가 10명, 본문 작품 자리 20개다. 실제 ZIP 안의 사진 수·작가 대응은 아직 확인하지 못했다.

표지 명칭: **동래구노인복지관 재가노인지원서비스센터**.
지원 문구: **본 제작물은 부산사회복지공동모금회의 지원으로 제작되었습니다.**

## 표지 레퍼런스 실제 확인

남산정 PDF의 첫 페이지 렌디션을 Adobe 도구로 직접 봤다. 흰 바탕, 넉넉한 외곽 여백, 3열 사진·글자 타일, 파스텔색 둥근 사각형, 가운데 제목 띠, 하단 기관/지원 로고 구성이었다.

이번 작업에서는 흰 여백·사진 모자이크·기관 표기의 위계만 참고한다. 유아적인 낱글자 타일과 색상 과다를 따라하지 않는다. 사진의 실제 방향을 확인해 전체 작품이 잘리지 않는 배치를 우선한다. 현재 JSX의 3열×4행 중 10개 사진 자리 배치는 검토용 초안이며 사진 수신 후 조정한다.

남산정 내지는 레퍼런스 범위 밖이다. 다른 고객의 기존 `08.png`는 검색에 함께 노출됐던 관련 없는 파일이며 책·입력 폴더·GitHub에 사용하지 않았다.

## 내지 원칙

- 1인 2쪽의 주인공은 작품 사진. 억지 크롭·색보정·생성 합성 없이 원본을 우선 보존.
- 이름 → 작품 → 제목·짧은 설명 순으로 읽히게 한다. 작가소개는 좌측 페이지에 여백을 확보해 추후 입력.
- 기본 본문은 Pretendard 14pt, 설명 13pt, 작은 표기 10.5~12pt의 검토값. 실제 원고 길이와 판형에 따라 시각 검수.
- 흰 여백·짙은 글자·가벼운 구분선 중심. 꽃·캐릭터·스티커 같은 불필요한 장식을 넣지 않음.
- 임시 A4 세로/3mm 도련. 인쇄소·고객 확인 전 납품 사양으로 확정하지 않음.
