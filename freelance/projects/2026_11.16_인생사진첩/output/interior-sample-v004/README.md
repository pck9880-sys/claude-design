# 내지 한 장 — v004

사진 위 원형과 글자를 삭제하고 사진 영역은 빈 프레임으로 유지했다. 상하좌우 여백 15mm. A4와 도련3mm는 기존 임시 검토 사양이다. 하단 이름·원고는 예시다.

- 사진빈프레임 PNG/SVG: 장식과 텍스트를 확인하는 한 페이지 시안.
- 가이드확인 PNG/SVG: 자홍색 점선이 15mm 여백선. 확인 전용이며 인쇄 장식이 아니다.
- `../../scripts/BuildInteriorSampleV004.jsx`: InDesign에서 프로젝트 폴더 구조를 유지한 채 실행. 페이지 및 부모 페이지 여백 15mm, 편집 가능한 텍스트·사진 프레임 생성. 새 버전 폴더로 INDD/IDML/PDF 출력하며 기존 파일을 덮어쓰지 않는다.

구조·여백 및 JSX 구문 검사 완료. 미리보기는 SVG를 렌더링한 것으로 실제 InDesign 출력은 아니다. 이 환경에 InDesign이 없어 앱 실행·오버셋·실물 출력은 미검증이다. 다른 23쪽에는 적용하지 않았다.
