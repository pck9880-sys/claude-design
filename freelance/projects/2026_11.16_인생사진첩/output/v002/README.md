# v002 전체 24p 배치 검토

- `전체24p_내지배치_검토도.png`: 표지와 모든 내지를 한눈에 보는 24쪽 검토도.
- `spread-02-03.png`: 인사말·프로그램 소개.
- `spread-04-05.png`: 작가 펼침면 가로/세로 변형 1.
- `spread-06-07.png`: 작가 펼침면 변형 2.
- `page-24.png`: 마무리 활동사진·참여자·기관 정보.
- 개별 페이지 SVG 24개와 펼침면 SVG 11개: 편집 좌표에 대응한 벡터 검토도.

사진·인사말·작가소개·작품 제목/설명 등 미수신 원고는 자리 표시다. 다른 고객 이미지나 생성 사진은 사용하지 않았다.

검토도는 자체 SVG 렌더링 결과이며 실제 Adobe PDF/INDD 출력물이 아니다. 실제 인쇄용 완성본·확정 디자인으로 취급하지 않는다. 판형 A4·도련 3mm는 임시값이다.

재생성: `python scripts/build_layout.py` 후 CairoSVG와 Pretendard가 있는 환경에서 `python scripts/render_layout_preview.py`.
