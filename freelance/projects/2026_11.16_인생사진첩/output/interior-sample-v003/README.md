# 레퍼런스 반영 내지 한 장 — v003

최신 사용자 지시: 첨부한 편집 레퍼런스의 전체 느낌을 참고하고 작가별 색상을 서로 다르게 하되 비슷한 톤으로 구성. 먼저 한 장만 보고 방향성 확인.

## 반영
- 큰 상단 사진과 넉넉한 흰 여백.
- 사진 위 흰색 원형 선과 ‘나의 시선’ 세로 타이포. 원형·글자는 네이티브 편집 객체로 생성하도록 구성.
- 사진 바깥의 얇은 열린 모서리 선.
- 하단의 가는 세로 제목 프레임, 작가소개 및 두 단의 작품 이야기.
- 인포그래픽이 필요 없는 사진 작품집이므로 레퍼런스 우측 페이지의 수치·도식은 복제하지 않음.

## 작가별 색

이번 한 장은 샌드 브라운(#A0896C) 제안이다. 방향 확인 뒤 작가마다 다른 저채도 색을 선택하되 비슷한 명도·채도로 통일한다. 선·작가명·소제목·장식에 포인트색을 쓰며 실제 작품 사진 자체의 색을 바꾸지 않는다. 현재 다른 작가/페이지에는 적용하지 않았다.

## 사진·글과 검증

작가명과 글은 이전 사용자 허용에 따른 예시다. 사진은 이번 시안용 새 생성 이미지로 실제 고객 작품이 아니다. 이 버전에서는 레퍼런스의 큰 사진 비율에 맞추기 위해 **예시 생성 사진에 한해** 프레임 안에서 비파괴 크롭했다. 원본 PNG는 변경하지 않았다. 실제 작품을 받을 때는 임의 크롭하지 않고 내용·방향에 맞춰 배치를 조정한다. 원형 글자가 중요한 피사체를 가리면 위치를 조정한다.

PNG/SVG는 자체 벡터 렌더링 디자인 검토 시안이며 실제 InDesign 앱의 출력 화면은 아니다. 편집 데이터는 data/interior_sample_v003.json/.jsxinc, InDesign 한 쪽 생성은 scripts/BuildInteriorSampleV003.jsx. 실제 앱 실행은 미검증.

한 페이지 범위·요소 좌표·실제 Pretendard 글자 폭·행 높이·JSX 구문을 확인했다. 사용자가 이 한 장을 보고 수정 방향을 정하기 전에는 전체 적용하지 않는다.
