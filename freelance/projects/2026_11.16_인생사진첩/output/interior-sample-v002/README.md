# 내지 한 장 — 실제 배치 느낌의 완성형 예시 v002

최신 사용자 요청: 자리 표시만 보여주지 말고, 임의 텍스트와 사진을 넣고 상단 타이틀·하단 영역까지 디자인해 보여줄 것.

## 시안
- 상단: 작품 제목을 크게, 작가소개는 오른쪽 별도 열로 구성.
- 중앙: 이번 시안용으로 새로 생성한 동네 골목 사진을 비례 배치. 원본 이미지 자체는 보정·합성·크롭하지 않음.
- 하단: 옅은 녹회색 색면, 작가의 한마디, 작품 설명, 책 제목과 쪽번호.
- 본문 12pt, 인용문 16pt, 타이틀32pt, Pretendard. 포인트 색은 사진의 녹색 대문과 어울리게 제안한 시안 색상.

**작가명 '김정숙', 작가소개·작품명·감상문은 사용자 요청에 따라 만든 예시이고 실제 참여자의 정보가 아니다. 사진도 이번 시안용 AI 생성 이미지로 실제 어르신 작품이 아니다.**

## 자산·편집
- 새 생성 사진: links/demo-sample/generated_alley_v001.png. 다른 고객 자료에서 가져오지 않음.
- 편집 좌표/예시 원고: data/interior_sample_v002.json, .jsxinc.
- 시안 생성: scripts/build_interior_sample_v002.py.
- InDesign 한 쪽 생성: scripts/BuildInteriorSampleV002.jsx. 텍스트·색면·사진 프레임은 개별 네이티브 객체로 생성하도록 준비했으며 실제 앱 실행은 아직 미검증.
- PNG/SVG는 자체 벡터 렌더링 디자인 검토 시안. 완성 INDD/인쇄 PDF라고 보고하지 않음.
- 이 예시를 실제 book-data.json·asset-mapping.csv의 고객 원고/작품으로 덮어쓰지 않는다. 사용자가 디자인을 확인하면 실제 자료로 교체한다.
- 다른 23쪽에 이 디자인을 적용하지 않았다. 피드백 후 적용 범위를 결정한다.

## 확인
- 생성 사진 실제 화면 확인.
- 합성된 한 페이지 PNG에서 겹침·잘림·위계 확인.
- 실제 Pretendard 폰트 폭 계산으로 모든 텍스트 줄이 각 영역 안에 들어감을 확인.
- InDesign JSX와 데이터의 JavaScript 구문 확인. 실제 Adobe 앱 출력은 미검증.
