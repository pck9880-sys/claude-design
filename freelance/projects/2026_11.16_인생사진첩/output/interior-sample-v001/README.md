# 내지 한 장 디자인 시안 — 사용자 검토용

대상은 4p, 작가소개와 작품 1장을 담는 대표 내지다. 새 디자인은 이 한 장에만 작성했으며 다른 페이지에는 적용하지 않았다.

- 큰 작품 사진, 상단 작가 정보, 하단 작품 제목·설명으로 읽는 순서 정리.
- 흰 여백과 짙은 글자, 절제한 녹회색 포인트. 유아적 장식 없이 차분한 작품집 방향.
- 실제 사진·성함·소개·작품 원고는 아직 받지 못해 해당 부분은 자리 표시.
- A4/3mm는 임시 검토 사양. 그림은 자체 SVG를 렌더링한 디자인 검토도이며 실제 InDesign 출력 화면은 아님.
- `scripts/BuildInteriorSample.jsx`가 같은 배치를 네이티브 1페이지로 생성하도록 준비. 실제 InDesign 앱 실행은 미검증.

다음 작업은 사용자 피드백을 받아 이 한 장을 수정하는 것이다. 확인 전 전체 내지에 자동 적용하지 않는다.
