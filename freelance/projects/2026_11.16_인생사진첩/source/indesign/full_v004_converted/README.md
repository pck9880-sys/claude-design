# Adobe 변환 문서 다운로드

INDD 패키지: https://to.adobe.com/oZa9S

IDML 패키지: https://to.adobe.com/tc2X0

Adobe 공식 변환 도구가 최신24쪽 PDF를 INDD/IDML로 변환했다고 성공 응답했다. 링크는 임시일 수 있으므로 내려받아 별도 보관한다. 이 폴더에 바이너리가 저장된 것은 아니다. 현재 실행환경은 다운로드403으로 차단되어 실물 파일 검사와 GitHub 바이너리 업로드는 미완료. 편집성·폰트·15mm 문서 여백·펼침면 설정은 실제 InDesign에서 확인해야 한다.
