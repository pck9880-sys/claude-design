# 작업: 폰트 추천 — {title}
{detail}

현재 문서 정보(사용 중인 폰트 포함): {context}

허용 출처: **눈누(noonnu.cc)** 와 **Adobe Fonts(fonts.adobe.com)** 만.
1. 용도(헤드라인/본문/캡션)별 후보 3~5개씩 고르세요. 이미 쓰는 폰트와의 조합도 고려하세요.
2. 눈누 폰트는 반드시 해당 폰트 페이지의 라이선스 표를 확인해 다음을 기록:
   인쇄·웹·영상·포장지·임베딩·BI/CI 사용 가능 여부, 수정/재배포 가능 여부. 확인 못 하면 "미확인"으로.
3. 상업적 사용이 불가하거나 미확인인 폰트는 추천표에서 제외하고 별도 "제외 목록"에만 적으세요.
4. `fonts.md`에 표: 폰트명 | 출처 | 링크 | 용도 | 라이선스 요약 | 어울리는 이유.
5. 폰트 파일을 다운로드하거나 설치하지 마세요. 설치는 사용자가 합니다 (Adobe Fonts는 Creative Cloud에서 '활성화').
6. 문서에 "누락(missing)" 상태 폰트가 있으면 맨 위에 경고로 적으세요.
